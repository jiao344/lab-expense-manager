# 机器人研究所日常经费管理

面向高校实验室与研究所长期使用的本地经费管理系统。采用 Flask + SQLite，数据保存在本机，可使用 Excel 交换数据，无需部署数据库服务器。

## 主要功能

- 专业财务仪表盘：余额、收支、本月支出、票据提醒、预算执行率和图表
- 收入与支出流水：新增、编辑、删除、组合查询和操作审计
- 分类预算：分类额度、执行进度和超支提示
- 票据管理：已收票、未收票、待补票与不需票据
- 人员统计：使用人、经办人和支出排行
- Excel：标准台账导出和批量导入
- 报表：月度收支、分类预算、人员排行和 A4 打印
- 数据安全：一键备份、恢复前自动安全备份、恢复文件校验
- 响应式中文界面：支持电脑、平板和手机浏览器

## Windows 启动

双击 `start.bat`，系统会自动安装依赖并在浏览器中打开。也可以在终端执行：

```powershell
python -m pip install -r requirements.txt
python app.py
```

然后访问 `http://127.0.0.1:5000`。

## 数据说明

- 主数据库：`data/expense.db`
- 自动/手动备份：`backups/`
- 首次运行会自动创建数据库和默认分类
- 建议每月下载一次完整备份，并复制到独立存储设备

## Excel 导入表头

首行至少包含：`日期`、`类型`、`金额`、`用途`。可选列包括：`分类`、`使用人`、`经办人`、`支付方式`、`票据状态`、`发票号`、`备注`。
